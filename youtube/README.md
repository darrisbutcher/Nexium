# Dragonfall channel graphics
All art is generated by the code in this folder (`font.py` = hand-drawn 5x7 pixel font, `art.py` = sprites/title renderer,
`build.py` = every asset). No stock images, no Mojang assets, no outside fonts. Palette comes from the Nexium textures.

Rebuild everything: `pip install pillow && python3 build.py` (outputs to `out/`).
New title: `python3 custom_title.py "EPISODE 2: EMBERS" 10 green|gold|purple out/ep2.png`
Font has A-Z, 0-9 and `! . : - # ' ?`.
